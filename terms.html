第 1 条（適用）

本規約は、個人開発者〔運営者: Arrow Code Lab〕（以下「運営者」）が提供するモバイルアプリケーション「何階だっけ」（英語名: Which Level?、以下「本アプリ」）の利用に関する条件を定めるものです。本規約は、Android 版・iOS 版の両方に適用されます。利用者は、本アプリを利用することにより、本規約に同意したものとみなします。

第 2 条（本アプリの内容）

本アプリは、自分の車を停めた場所（位置・階・柱番号・写真・メモ）を記録し、方位・距離・地図で車まで案内するためのツールです。位置情報・気圧による階の判定、写真からの文字の読み取り、地名の取得は、端末のセンサーや電波の状況、建物の構造等により誤差が生じることがあり、運営者はその正確性を保証しません。案内に従って移動する際は、周囲の安全と交通ルールを優先してください。

第 3 条（データの管理）

  • 本アプリのデータは利用者の端末内にのみ保存され、運営者は保管していません。データの取り扱いはプライバシーポリシーに定めるとおりです。
  • Android では、データはバックアップされません。iOS では、端末の設定により iCloud 等のバックアップに含まれることがありますが、運営者はバックアップを管理していません。いずれの場合も、端末の故障・紛失・機種変更、本アプリのアンインストール等によりデータが失われたとき、運営者は復元できません。
  • 車に戻った後の記録の写真は、設定した保存期間を過ぎると自動で削除されます（お気に入りを除きます）。
  • 駐車位置を共有する場合、共有した情報の取り扱いは利用者の責任で行ってください。他人が写り込んだ写真や他人の情報を扱う場合は、法令を遵守してください。

  • 料金は、アプリ内の購入欄および各ストアの購入画面に表示されます。
  • 機種変更や再インストールの後は、同じ Google アカウントまたは Apple ID で、アプリの設定画面の「購入を復元」から購入を戻せます。Android と iOS の間で購入を引き継ぐことはできません。
